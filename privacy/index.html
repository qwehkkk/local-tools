隐私说明

你的文件、文本、以及访问记录，到底发生了什么。能验证的地方都写清怎么验证。

没有接收文件的服务器

一句话结论

这个站点没有能接收你文件的服务器。所有处理都在你自己的浏览器里完成，关掉网络一样能用。

你的文件去了哪里

  • 读进内存：你选中的文件由浏览器读进页面内存，处理也在内存里做完。
  • 写回你的磁盘：结果是浏览器自己触发的下载，存到你电脑上，不经过任何中转。
  • 不上传：页面里没有任何上传接口。唯一会额外下载的是 PDF 工具用到的那份引擎代码， 它不是你的文件，而且只在第一次真正处理 PDF 时才下载。
  • 不存本地：不用 Cookie、localStorage、IndexedDB 保存你的内容。脱敏工具的映射表也只存在内存里， 要不要留下来由你自己决定（下载 CSV）。
  • 刷新即清空：不是「我们承诺删除」，而是从来没离开过你的电脑。

站点本身跑在哪

页面是纯静态文件，托管在 GitHub Pages（GitHub / 微软的基础设施）。作为托管方，它会记录常规访问日志： 来源 IP、时间、User-Agent、请求的路径。

这些属于托管层面的记录，与本站代码无关，仓库所有者拿不到（GitHub Pages 不向仓库提供访问日志）。 换句话说：我们自己也没有能力看到谁来过、传了什么 —— 后者本来就不存在。

没有统计脚本，没有广告脚本，没有 Cookie

  • 页面不加载任何第三方脚本：没有 Google Analytics、没有百度统计、没有广告代码。
  • 字体用你系统自带的，不请求外部字体服务；图标和样式都是自己写的。
  • 怎么验证：F12 → Network 面板，按 Domain 排序。除了本站域名，不应该出现别的域名。
  • 如果以后要加（比如为了知道到底有没有人在用），会先在这一页写清楚加了什么、收集什么， 而不是先加上再补说明。

第三方代码

  • pdf-lib（MIT 许可）：PDF 工具的合并与拆分引擎。只在第一次处理 PDF 时加载， 文件来自本站，不从任何 CDN 拉取。
  • 其余全部是自己写的原生 JavaScript，没有框架、没有构建步骤，浏览器直接执行。

你自己怎么验证

  1. 按 F12 打开开发者工具，切到 Network（网络） 面板，勾上 Preserve log。
  2. 拖一个文件进去，点生成或下载。
  3. 看列表：不应该出现任何一条携带你文件内容的请求。处理前后的请求数应该是一样的。
  4. 更彻底的做法：切成 Offline（或直接断网）后刷新页面，功能照样完整可用。
  5. 再彻底一点：把源码 clone 下来读完再信。仓库地址在 关于页。

必须说清楚的三件事

  • 本地处理不等于设备绝对安全。浏览器扩展、输入法、剪贴板同步、系统录屏都在这个页面之外， 它们能否看到内容不由本页决定。在公共电脑上处理敏感材料，风险不在这个网站。
  • 映射表 CSV 是敏感数据。用「占位符」方式脱敏后导出的映射表里是明文对应关系， 泄露它就等于泄露原文。别和脱敏后的文件放在一起，也别一起发出去。
  • 这里降低的是「把文件交给陌生服务器」的风险，不降低「设备被入侵」「文件被同事看到」这类风险。
