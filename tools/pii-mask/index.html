映射表
映射表本身就是敏感数据：别和脱敏后的文件一起发出去。
关于准确率，说清楚比说好听重要：
  • 能可靠识别：身份证号（带校验位验证）、手机号、银行卡号（Luhn 校验）、统一社会信用代码、邮箱、车牌、IP、地址、带「订单号/账号」等关键词的编号。
  • 只有上下文才识别：姓名需要前面有「姓名／甲方／收件人／患者」这类字段名。裸人名（例如正文里随机出现的「王小明」）不会被自动标记 —— 强行识别会误伤大量正常词汇，请在脱敏后自己扫一眼。
  • 「机构名称（泛匹配）」默认关闭：任何带「公司／银行／医院」后缀的短语都会命中，误报偏多。但「公司名称／开票抬头／开户行」这类字段触发的单位名是默认开启的，准确度高。
  • 这是辅助工具，不承诺「保证没有遗漏」。对外发布前请自己通读一遍脱敏结果。
怎么验证它真的没上传： 按 F12 打开开发者工具 → Network 面板 → 在左边粘贴内容。你会看到面板里没有任何一条因为你输入而产生的请求（页面加载时的 HTML/CSS/JS 除外）。右上角那个计数就是本页脚本发出的请求数，实现上直接接管了 fetch 与 XMLHttpRequest。断网状态下刷新这个页面，功能完全一样。
