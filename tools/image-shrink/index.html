怎么验证图片真的没上传

按 F12 打开开发者工具 → 切到 Network（网络）面板 → 拖入一张图片。 你会看到面板里没有任何一条由这张图片产生的请求。右上角的计数也是同一个意思，但它只是页面自己数自己， 真正可信的是 Network 面板。断网状态下这个页面同样能完整工作。

几件如实说明的限制

  • HEIC / HEIF 不支持（iPhone 的默认格式）。浏览器本身解不了，需要先在手机或系统里转成 JPG。
  • GIF 动图只处理第一帧，动画会丢失。要做动图请另找工具。
  • PNG 是无损格式，质量参数对它无效，「按目标大小」也压不下去，只能靠缩小边长。
  • JPEG 没有透明通道，原图的透明区域会被填成白色。需要保留透明请选 WebP 或 PNG。
  • 超大图（单边超过 8000 px）可能因内存不足失败，会如实报错而不是静默跳过。
  • 压缩是有损的，反复压缩会持续掉画质。建议始终从原图重新压缩。

为什么不做上传

图片里最常见的就是人脸、证件、家庭住址、车牌。上传到服务器再「承诺不留存」， 和压根不上传是两件事 —— 前者依赖对方守规矩，后者不依赖任何人的承诺。
